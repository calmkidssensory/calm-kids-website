CALM KIDS SENSORY — FREE SAMPLER EMAIL CAPTURE
Google Sheets + Apps Script setup

This is the backend for the "3-Page Free Sampler" forms on our book pages
(website/books/*.html, wired up by website/js/sampler-form.js). It logs every
request to a Google Sheet and emails the visitor their sampler PDF link.

------------------------------------------------------------
STEP 1 — Create the Sheet
------------------------------------------------------------
1. Go to sheets.google.com and create a new, blank spreadsheet.
2. Name it something like "Calm Kids Sensory — Sampler Requests".
3. Rename the first tab (bottom-left) to "Requests" if you'd like — the
   script below works with whatever the active sheet is, so this is optional.

------------------------------------------------------------
STEP 2 — Add the Apps Script
------------------------------------------------------------
1. In the sheet, open Extensions > Apps Script.
2. Delete any starter code in Code.gs and paste in EVERYTHING between the
   dashed lines below.
3. Click the save icon (or Ctrl+S / Cmd+S).
4. From the function dropdown at the top, choose "setupSheetHeaders" and
   click Run once. This writes the column headers into row 1. The first run
   will ask you to authorize the script — that's expected, since it needs
   permission to edit this sheet and send email on your behalf.

------------------------------------------------------------ START OF SCRIPT
/**
 * Calm Kids Sensory — free sampler request handler.
 *
 * Receives a POST from a book page's sampler form, logs the request as a
 * new row, and emails the visitor a direct link to their sampler PDF,
 * along with the book's Amazon listing in case they'd like the paperback.
 */

// One-time helper: run this manually from the Apps Script editor to write
// the header row. Safe to re-run — it only touches row 1.
function setupSheetHeaders() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  sheet.getRange(1, 1, 1, 5).setValues([
    ["Date", "Email", "Book", "Sampler PDF", "Amazon Link"],
  ]);
}

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

  var email = (e.parameter.email || "").trim();
  var book = (e.parameter.book || "").trim();
  var pdfUrl = (e.parameter.pdfUrl || "").trim();
  var amazonUrl = (e.parameter.amazonUrl || "").trim();

  if (!email || !book || !pdfUrl) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: "error", message: "Missing required field" }))
      .setMimeType(ContentService.MimeType.JSON);
  }

  // 1) Log the request as a new row.
  sheet.appendRow([new Date(), email, book, pdfUrl, amazonUrl]);

  // 2) Send the sampler email.
  sendSamplerEmail(email, book, pdfUrl, amazonUrl);

  return ContentService
    .createTextOutput(JSON.stringify({ status: "ok" }))
    .setMimeType(ContentService.MimeType.JSON);
}

function sendSamplerEmail(email, book, pdfUrl, amazonUrl) {
  var subject = "Your quiet coloring pages — " + book;

  var amazonLine = amazonUrl
    ? "\n\nIf your family enjoys these pages, the full " + book + " is available on Amazon:\n" + amazonUrl
    : "";

  var body =
    "Hello,\n\n" +
    "Thank you for asking for a free sampler from " + book + ". Here are your three pages, " +
    "ready to open and print at home:\n\n" +
    pdfUrl +
    amazonLine +
    "\n\n" +
    "We hope they bring a little quiet, screen-free focus to your day.\n\n" +
    "Warmly,\n" +
    "Calm Kids Sensory\n\n" +
    "Connect With Us:\n" +
    "YouTube: Calm Kids Sensory\n" +
    "Amazon Author Page, PikMe Publishing: https://www.amazon.com/author/calmkidssensory\n" +
    "Instagram: @calmkidssensory\n" +
    "TikTok: @calmkidssensory\n" +
    "Pinterest: CalmKidsSensory";

  MailApp.sendEmail(email, subject, body);
}
------------------------------------------------------------ END OF SCRIPT

------------------------------------------------------------
STEP 3 — Deploy as a Web App
------------------------------------------------------------
1. In the Apps Script editor, click Deploy > New deployment.
2. Click the gear icon next to "Select type" and choose "Web app".
3. Fill in:
     Description:      Sampler request handler
     Execute as:        Me (your Google account)
     Who has access:    Anyone
4. Click Deploy. Google will ask you to authorize the script — approve it
   (you'll see an "unverified app" warning since this is your own private
   script; click Advanced > Go to (project name) to continue).
5. Copy the "Web app URL" it gives you. It looks like:
     https://script.google.com/macros/s/AKfycb.../exec

------------------------------------------------------------
STEP 4 — Connect it to the website
------------------------------------------------------------
1. Open website/js/sampler-form.js.
2. Find this line near the top:
     var GAS_WEB_APP_URL = "PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE";
3. Replace the placeholder with the Web app URL you copied in Step 3.
4. Save, commit, and push. Every "Send Me My Free Pages" button on the site
   will now log to your sheet and email the sampler automatically.

------------------------------------------------------------
NOTES
------------------------------------------------------------
- If you ever need to re-authorize or update the email wording, go back into
  Extensions > Apps Script from the sheet, edit, save, then Deploy >
  Manage deployments > edit (pencil icon) > New version > Deploy. Editing the
  code alone does not update a live deployment — you must publish a new
  version for changes to take effect.
- The website sends the request with mode: "no-cors", which is a known
  limitation of Google Apps Script Web Apps not sending browser-readable CORS
  headers. This means the site cannot read Google's response and shows the
  success message as soon as the request leaves the browser. If you want to
  confirm delivery, check the sheet directly.
- Nothing in this file needs to be uploaded anywhere — it's a reference copy
  of the script that lives on Google's side once deployed.

------------------------------------------------------------
TROUBLESHOOTING — rows appear in the sheet but no email arrives
------------------------------------------------------------
This means the script hasn't been granted permission to send mail yet. Apps
Script only asks for the permissions a function actually touches the first
time you run it, and running setupSheetHeaders alone (Sheets access only)
does not trigger the Gmail-send permission prompt.

Fix:
1. In the Apps Script editor, from the function dropdown choose "doPost".
2. Click Run. It will fail immediately with a small "e is not defined"
   error — that's expected and fine, doPost needs a live request to run
   properly. What matters is that clicking Run surfaces an "Authorization
   required" prompt first.
3. Click through it: Review permissions > pick your account > Advanced >
   Go to (project name) > Allow. Make sure the Gmail send permission is
   included in what you approve, not just Sheets.
4. No redeploy needed — this authorization applies immediately to the
   existing Web App deployment. Test a sampler form on the site again.
